# Behind the BDRC E-Text Corpus: what we built

_A series from WeBuddhist (Dharmaduta Services LLP), in collaboration with the Buddhist Digital Resource Center (BDRC) and with the support of the Khyentse Foundation._

---

Tibetan Buddhist literature survives in tens of millions of page images. The **BDRC E-Text Corpus** project is turning it into a clean, catalogued, openly published and AI-ready text collection. WeBuddhist is BDRC's main delivery partner. We run the annotation teams, build the tools, scan books in monastic libraries and prepare the data that trains the OCR models.

Each post below covers one deliverable, with the work summed across the whole project.
